# 부엉이 파일 지킴이 (C_Inotify)

리눅스 **inotify**로 폴더 안의 파일 · 디렉터리 이벤트(생성 · 수정 · 삭제 · 이동)를 실시간으로 탐지하고,
기준 시각 이후 무엇이 바뀌었는지 보여 주는 C++ GUI 프로그램입니다.

## 과제 요구사항 대응

| 요구사항 | 구현 |
|---|---|
| inotify로 파일 이벤트 탐지 | `inotify_init1` · `inotify_add_watch`로 폴더와 모든 하위 폴더 감시 (`src/Watcher.cpp`) |
| 파일 · 디렉터리 추적 | 생성 · 수정 · 삭제 · 이동을 파일과 폴더 모두 구분해 표시. 새로 생긴 폴더 · 옮긴 폴더도 자동으로 계속 감시 |
| git처럼 변경사항 확인 | 기준 시각 대비 새로 생김 / 고쳐짐 / 사라짐 / 다시 만듦 목록과 바뀐 줄(+ 초록 / − 빨강) |
| 보기 좋고 쓰기 쉬운 UI | 이벤트마다 반응하는 캐릭터, 색으로 구분한 이벤트 배지, 종류별 거르기, 한국어 화면 |

## 실행 (Ubuntu / WSL)

```bash
cd C_Inotify
make                    # 필요한 패키지 설치 → 빌드 → 실행 (앱에서 "폴더 열기")
make DIR=~/test1        # 그 폴더를 바로 열어서 실행
make test               # 자가 검사 → "all passed"
```

설치되는 것: `g++` `cmake` `qt6-base-dev`(없으면 `qtbase5-dev`) `fonts-noto-cjk` — 이미 있으면 건너뜁니다.
WSL에서는 감시 폴더를 리눅스 쪽(`~/…`)에 두세요. `/mnt/c`, `/mnt/d` 같은 Windows 드라이브는 inotify 이벤트가 오지 않습니다.

## 화면

- **위쪽**: 감시 중인 폴더 경로, `폴더 열기`, `감시 시작/중지`
- **캐릭터 무대**: 이벤트가 생기면 담당 캐릭터가 반응하고 말풍선으로 알려 줍니다. 아래 숫자는 종류별 이벤트 수입니다. 캐릭터를 누르면 그 종류만 목록에 보입니다(부엉이 = 전체).

  | 캐릭터 | 이벤트 | 반응 |
  |---|---|---|
  | 부엉이 | 감시 | 감시 중엔 눈 뜨고 이벤트 쪽을 봄, 멈추면 잠 |
  | 새싹이 (초록) | 생성 | 떡잎이 자라고 반짝임 |
  | 뚝딱이 (주황) | 수정 | 망치질 + 불꽃 |
  | 사르르 (빨강) | 삭제 | 반투명해지며 떠오름 |
  | 이사짱 (파랑) | 이동 · 이름 바꾸기 | 옆으로 휙 + 먼지 |

- **실시간 탭**: 이벤트 목록(종류 · 시간 · 경로). `전체 ▾`로 종류 거르기, `화면 지우기`
- **변경사항 탭**: 폴더를 연 순간(또는 `지금부터 다시`를 누른 순간) 대비 바뀐 파일 목록. 파일을 누르면 바뀐 줄을 보여 줍니다.

## 이벤트 판정 규칙

| 한 일 | 표시 |
|---|---|
| `touch a.txt` (빈 파일) | 생성 |
| `echo hi > a.txt`, `cp`, vim으로 새 파일 저장 | 생성 + 수정 |
| `echo hi >> a.txt`, vim으로 기존 파일 저장 | 수정 |
| `sed -i` (임시 파일에 써서 바꿔치기) | 수정 |
| `mv a.txt b.txt` | 이동 a.txt → b.txt |
| 감시 폴더 밖으로 / 안으로 옮기기 | 삭제 / 생성 |
| `rm`, `rm -r` | 삭제 (폴더는 안쪽부터) |
| `chmod` | 표시 안 함 (내용이 그대로) |

- 편집기 임시 파일(vim `.swp` · `.swx` · `~` 백업 · `4913` · `.viminfo`, emacs `.#`)과 앱 자신의 설정 파일(`QtProject.conf`)은 기본으로 무시합니다.
- 감시 폴더에 `.trackignore`를 만들고 `*.o`, `build` 같은 패턴을 한 줄에 하나씩 적으면 그것도 무시합니다.
- 감시 폴더에는 아무 파일도 만들지 않습니다. 비교 기준은 앱이 켜져 있는 동안 메모리에만 있습니다(1MB 넘는 파일은 줄 비교 생략).

## 테스트 방법

1. 첫 번째 터미널: `cd ~/C_Inotify && make DIR=~/test1`
2. 두 번째 터미널(Windows Terminal의 `+` 옆 `⌄` → Ubuntu): `cd ~/test1`
3. 두 번째 터미널에서 명령을 치며 앱을 확인합니다.

```bash
echo hello > a.txt       # 생성 + 수정 (새싹이 · 뚝딱이)
echo more >> a.txt       # 수정
vi main.c                # 내용 쓰고 :wq → 생성 + 수정
mkdir -p src/lib         # 폴더 생성 2개
touch src/lib/x.c        # 하위 폴더 안 파일도 생성으로 잡힘
mv a.txt b.txt           # 이동 (이사짱)
rm b.txt                 # 삭제 (사르르)
rm -r src                # 안쪽부터 차례로 삭제
```

4. **변경사항** 탭에서 바뀐 파일과 바뀐 줄을 확인하고, `지금부터 다시`로 기준을 새로 잡습니다.

## 구조

```
src/Watcher.*         inotify 래퍼: 재귀 감시, 이동 짝 맞추기, 폴더 이동 시 감시 경로 갱신, 편집기 저장 방식 정리 (Qt 없음)
src/Tracker.*         기준 상태 기억, 바뀐 파일 목록, 줄 비교(LCS), 무시 목록 (Qt 없음)
src/CharacterStage.*  캐릭터 무대 (QPainter로 직접 그림, 그림 파일 없음)
src/MainWindow.*      화면. inotify fd를 QSocketNotifier로 Qt 이벤트 루프에 연결
src/main.cpp          실행 시작점 (한국어 번역 로드)
tests/core_test.cpp   Watcher + Tracker 자가 검사 (실제 inotify로 확인)
```

기술: C++17 · Linux inotify · Qt 6 (Qt 5.15도 빌드 가능) · CMake
